# @starter/web

## Why this exists

The product: React Router v7 app + Hono API on a single Cloudflare Worker.

## Architecture

- `worker.ts` — Worker entry: `handle(build, app, { getLoadContext })`; the `./build/server` import is generated by `pnpm build` and carries a `@ts-expect-error`
- `server/index.ts` — Hono app: `authMiddleware` (db + auth per request) → Better Auth at `/api/auth/**` → versioned API at `/api/v1`
- `server/api.ts` — `OpenAPIHono` routes; every route declares a zod schema (that's where the OpenAPI spec comes from)
- `load-context.ts` — passes `db` and `auth` into React Router loaders (`context.db` / `context.auth`)
- `app/routes.ts` — explicit route config (NOT file-based routing)
- `app/routes/_examples/` — reference pages, not registered as routes

## Rules

- New page: add to `routes.ts` → create route file → `npx react-router typegen`
- New API route: add to `server/api.ts` with OpenAPI schema → `pnpm api:spec` → add matching MCP tool in `apps/mcp`
- Auth guard: `redirect("/login")` in the loader when there's no session (see `dashboard.tsx`); child routes rely on the dashboard layout loader — but treat any child loader that touches sensitive data as needing its own check (audit #10)
- Secrets: never in `wrangler.jsonc` — `.dev.vars` locally, `wrangler secret put` in production
- Deploy only via `pnpm deploy:web` (runs the verify gate)

## Testing

- `server/__tests__/` — Hono routes tested directly via `apiApp.request()`, no Worker runtime needed
- **Coverage target: `server/` 90%+** — every API route gets a unit test asserting status, shape, and the version/spec contract
- Routes/loaders/UI have no unit target — they're covered by `tests/e2e/` (auth flow, health, spec); keep e2e locators role-based (`getByRole`), not `text=` (strict-mode ambiguity burned us before)
- **Stop any running dev server before `pnpm test:e2e`.** Playwright reuses a server on 5173, but e2e global-setup runs `db:reset` — a pre-existing server keeps a handle to the dropped D1 file and all auth calls fail with `SQLITE_CANTOPEN`
